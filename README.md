# AI Trading Research Agent
Autonomous multi-agent equity research pipeline built with **LangGraph**, **Groq**, **Tavily**, and **yfinance**.

## Quickstart
1. Copy `.env.example` to `.env` and add `GROQ_API_KEY` and `TAVILY_API_KEY`.
2. Activate venv: `venv\Scripts\activate`
3. Run: `python main.py`
